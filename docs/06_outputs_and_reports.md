# Output Specification

## Factorial pattern

The factorial pattern output shall include each retained feature, its loading on each extracted factor, and whether it meets the minimum loading threshold.

## Feature count table

The feature count table shall contain one row per text and one column per retained feature.

## Factor score table

The factor score table shall contain one row per text and one column per extracted factor.

## High-scoring text samples

For each factor, the system shall provide a sample of texts from the positive and negative poles.
