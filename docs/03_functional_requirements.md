# Functional Requirements

## Corpus upload

The system shall allow the user to upload a corpus consisting of multiple texts.

## Language selection

The system shall allow the user to specify the corpus language before processing.

## POS filtering

The system shall allow the user to enable or disable filtering by part-of-speech category.

## Correlation method selection

The system shall select the correlation method automatically based on the selected data type.

## Initial factor analysis

The system shall perform an initial factor analysis and present an eigenvalue list to the user.

## Final factor extraction

The system shall allow the user to choose the number of factors and then perform final factor extraction.
