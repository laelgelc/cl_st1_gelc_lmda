# Product Brief

## Purpose

The application supports corpus-based discourse analysis using Lexical Multidimensional Analysis by automating corpus processing, feature extraction, statistical analysis, factor scoring, and production of interpretation aids.

## Target users

Researchers in applied linguistics, corpus linguistics, discourse studies, and related fields who may not have advanced programming or statistical software expertise.

## Core value

The tool reduces the technical burden of conducting LMDA by allowing users to provide a corpus and a small number of analysis settings.
